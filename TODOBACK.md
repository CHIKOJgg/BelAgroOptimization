# DAOS — Задачи и предложения для бэкенда (TODOBACK)

> Данный файл аккумулирует все запросы на новые эндпоинты, оптимизации, расширение схемы данных (DTO) и пожелания к серверной части DAOS (FastAPI / Pyomo / GLPK).
> **Согласно регламенту разработки, бэкенд (`app/`) остаётся неприкосновенным со стороны фронтенд-команды.** Все необходимые доработки фиксируются исключительно в этом документе.

---

## 📌 Текущий статус бэкенда
- **Версия API**: 2.4.0
- **Базовый префикс**: `/api`
- **Документация Swagger**: `/docs` (OpenAPI 3.1)
- **Математический солвер**: Pyomo 6.x + GNU Linear Programming Kit (GLPK 5.x)
- **База данных**: PostgreSQL (Asyncpg / SQLAlchemy) + Mock fallback при отсутствии подключения

## 📋 Список доработок и новых эндпоинтов (Wishlist)

### 1. 🔄 Пакетное обновление параметров (Batch Updates)
- **Текущее состояние**: Сейчас обновление параметров полей (`PUT /api/scenarios/{id}/fields/{field_id}`), культур (`PUT /crops/{crop_code}`) и т.д. происходит строго по одному объекту.
- **Потребность**: Эндпоинты пакетного сохранения:
  - `POST /api/scenarios/{scenario_id}/fields/batch` — сохранение измененного массива полей после импорта Excel/CSV.
  - `POST /api/scenarios/{scenario_id}/crops/batch` — массовое обновление нормативов севооборота и удобрений.
- **Приоритет**: Средний.

### 2. 📡 Server-Sent Events (SSE) / WebSockets для стриминга расчета
- **Текущее состояние**: Сейчас фронтенд опрашивает статус задачи (`GET /api/optimization/status/{job_id}`) поллингом с интервалом 400 мс.
- **Потребность**: Добавить эндпоинт `GET /api/optimization/stream/{job_id}` (Server-Sent Events) для трансляции логов GLPK в реальном времени без избыточного HTTP-поллинга.
- **Приоритет**: Желательно (Performance enhancement).

### 3. 📊 Экспорт аналитического PDF/Excel отчета на стороне сервера
- **Текущее состояние**: Экспорт в Excel (`.xlsx`) генерируется на клиенте через SheetJS, а графики скачиваются по статическим ссылкам `/plots/`.
- **Потребность**: Эндпоинт `GET /api/optimization/results/{scenario_id}/report.pdf` для генерации официального бланка Минсельхозпрода РБ с титульным листом, сводными таблицами и графиками.
- **Приоритет**: Низкий (на текущий момент экспорт полностью закрыт на клиенте).

### 4. 🗺️ GeoJSON координаты контуров реальных полей (ГИС интеграция)
- **Текущее состояние**: Векторные контуры полей зафиксированы на клиенте в SVG-системе координат 800×480.
- **Потребность**: Добавить в модель `FieldDataDto` опциональное поле `geojson_geometry: dict | None` для загрузки контуров полей из Национального кадастрового агентства Беларуси (НКА РБ) / WGS84.
- **Приоритет**: Долгосрочный.
